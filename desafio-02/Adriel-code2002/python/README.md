Desafio 02 - Primos

Objetivo

Listar todos os números primos entre 1 e 10.000 utilizando Python 3.

Como funciona

O programa verifica cada número a partir de 2. Para descobrir se ele é primo, testa se existe algum divisor entre 2 e a raiz quadrada do número.

Se encontrar um divisor exato, o número não é primo. Caso contrário, é considerado primo e exibido na tela.

Como executar

No terminal, execute:

python primos.py

Resultado

O programa lista os 1.229 números primos existentes entre 1 e 10.000.
