# Desafio 02

## Objetivo

Criar um algoritmo que encontre todos os números primos entre 1 e 10000 (dez mil).

## Resolução

Utilizei o [Crivo de Eratóstenes](https://pt.wikipedia.org/wiki/Crivo_de_Erat%C3%B3stenes) para criar o algoritmo

## Rodar

Para rodar o programa será necessário ter Go instalado. Use o seguinte comando para rodar:
```
$ go run .
```
