# Desafio 02 - Numeros Primos
 
## Descricao
 
Programa que lista todos os numeros primos entre 1 e 10000
usando o algoritmo Crivo de Eratostenes.
 
## Linguagem
 
Java (OpenJDK 17)
 
## Como executar
 
### Compilar

javac Primos.java

 
### Executar

java Primos

 
### Exemplo de saida

2
3
5
7
11
...
9973
```
